# ElvUI Chat Textures

ElvUI Chat Textures is an update to the original addon by Pettrah (SileniaD) of Lightbringer. It provides subtle crest backgrounds for ElvUI chat panels and an in-game window with copyable texture paths.

## Features

- 40 class, faction, and racial backgrounds.
- Crests at 40% opacity on solid-black 256 × 128 backgrounds.
- Alphabetized Classes, Factions, and Races groups with spaced entries.
- A movable, scrollable catalog with Blizzard's default window and control styling.
- Uses ElvUI's general font when ElvUI is enabled.
- Displays the version from the TOC in the window header.

## Settings

Type `/ect` to open or close the texture catalog. Click a path to select it and copy the complete path. Type `/ec` to open ElvUI settings, go to **Chat > Panels**, and scroll to the bottom. Paste your chosen path into **Panel Texture (Left)** and **Panel Texture (Right)**.

The catalog does not change your chat panel settings. Close it with the X button or Escape.

## Installation

1. Download the zip file and unarchive it.
2. Place the `ElvUI_ChatTextures` folder inside:

   `World of Warcraft/_retail_/Interface/AddOns/`

3. Ensure it is properly installed by checking:

   `World of Warcraft/_retail_/Interface/AddOns/ElvUI_ChatTextures/ElvUI_ChatTextures.toc`

4. Enable **ElvUI Chat Textures** from the AddOns menu on the character-selection screen.
5. Log in or type `/reload`.
